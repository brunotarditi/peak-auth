Documentación de Peak Auth

Peak Auth es un Proveedor de Identidad (IdP) centralizado, diseñado para ser rápido, seguro e integrarse fácilmente con tu ecosistema de aplicaciones mediante JWT Asimétrico (RSA-256).

JWT Asimétrico (RSA-256)

A diferencia de los JWT tradicionales que usan una clave secreta única (HS256) compartida entre todas las aplicaciones, Peak Auth utiliza criptografía asimétrica.

  • Clave Privada: Solo Peak Auth la conoce. Se utiliza exclusivamente para firmar los tokens JWT cuando un usuario inicia sesión.
  • Clave Pública: Es distribuida a todas las aplicaciones satélite. Permite a cualquier aplicación verificar matemáticamente que un token fue emitido por Peak Auth, pero no les permite crear nuevos tokens falsos.
Nota de Seguridad Nunca compartas ni expongas el archivo jwt_private.pem. Las aplicaciones de terceros solo necesitan jwt_public.pem para validar los accesos.

Flujo de Single Sign-On (SSO)

El flujo de inicio de sesión descentralizado permite a los usuarios autenticarse una sola vez en el sistema central:

  1. El usuario intenta acceder a App Cliente.
  2. Como no está autenticado, la app cliente lo redirige al portal de login de Peak Auth, pasando su Client ID en la URL.
  3. Peak Auth valida credenciales, aplica políticas de seguridad (intentos fallidos, reglas) y genera un Access Token (JWT) y un Refresh Token.
  4. Peak Auth retorna al usuario a la App Cliente adjuntando el código o los tokens generados.
  5. La App Cliente utiliza la Clave Pública para validar el JWT y permite el ingreso.
