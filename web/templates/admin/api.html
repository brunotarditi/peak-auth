Referencia de API

Endpoints de integración pública para interactuar con Peak Auth desde tus microservicios y aplicaciones cliente.

POST /api/v1/login

Autentica a un usuario y genera un JWT firmado mediante criptografía asimétrica. Requiere las credenciales del cliente (App). 

{
  "email": "user@example.com",
  "password": "SecurePassword123!",
  "client_id": "mi-app-id",
  "client_secret": "secret-de-la-app"
}

Respuesta Exitosa

{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5c...",
  "refresh_token": "rt_28f2j9fj28f...",
  "expires_in": 3600
}

POST /api/v1/refresh

Obtiene un nuevo Access Token enviando un Refresh Token válido, sin necesidad de pedir usuario y contraseña de nuevo. Aplica rotación de tokens (el viejo muere, uno nuevo nace). 

{
  "refresh_token": "rt_28f2j9fj28f..."
}

Validación en tu Aplicación

Tu aplicación NO necesita llamar a Peak Auth para validar cada request. En su lugar, usa el archivo público jwt_public.pem. 

// Ejemplo en Node.js
const jwt = require("jsonwebtoken");
const fs = require("fs");

const publicKey = fs.readFileSync("./jwt_public.pem", "utf-8");

app.get("/recurso-protegido", (req, res) => {
    const token = req.headers.authorization.split(" ")[1];
    try {
        // Validación local (sin latencia de red)
        const decoded = jwt.verify(token, publicKey, { algorithms: ["RS256"] });
        res.json({ user: decoded.email });
    } catch (err) {
        res.status(401).send("Token Inválido");
    }
});
